# NusaExplore 🇮🇩

**Explore Indonesia, One Culture at a Time.**

NusaExplore adalah website frontend interaktif untuk menjelajahi keberagaman budaya Indonesia melalui wilayah-wilayah Nusantara.

## ✨ Fitur
- Pilihan wilayah Indonesia
- Culture spotlight
- Pakaian adat, rumah adat, kuliner, dan kesenian
- Search budaya
- Mini quiz
- Dark / light mode
- Responsive design
- Tidak membutuhkan backend atau framework

## 🚀 Menjalankan
Cukup buka `index.html` di browser.

## 🌐 GitHub Pages
1. Upload semua file ke repository.
2. Buka **Settings → Pages**.
3. Pilih branch `main` dan folder `/root`.
4. Simpan, lalu tunggu GitHub Pages aktif.

## Teknologi
HTML · CSS · JavaScript
